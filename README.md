# GymSportFit

Actúa como un desarrollador web Full-Stack y un experto en diseño UI/UX. Tu tarea es diseñar y estructurar el código para la página web de un gimnasio moderno y de alto rendimiento. La prioridad es que la experiencia de usuario (UX) sea inmersiva, visualmente impactante y altamente interactiva.
Requisitos específicos que debes implementar:
Integración de Imágenes Propias: Diseña la interfaz utilizando las imágenes que te adjunto en este mensaje (o deja los contenedores exactos con etiquetas claras para que yo pueda insertar las rutas de mis archivos locales fácilmente). Las imágenes deben tener un tratamiento visual elegante (filtros sutiles, bordes oscurecidos o recortes dinámicos).
Escaparate Interactivo de Equipo: Crea una sección interactiva para que el consumidor explore las instalaciones y las máquinas. Implementa una galería dinámica, tarjetas 3D que reaccionen al movimiento del cursor (efectos de hover o tilt), o un pequeño mapa/carrusel interactivo donde al hacer clic en un área del gimnasio se revelen las máquinas y para qué sirven, usando animaciones fluidas.
Sistema de Registro y Base de Datos (Escalabilidad): Desarrolla el portal de "Registro/Login" y proporciona la estructura backend necesaria (o la configuración para servicios como Supabase, Firebase o PostgreSQL) capaz de almacenar y gestionar de forma eficiente una base de datos de al menos 10,000 miembros. Debe incluir campos de nombre, correo, tipo de membresía y estado de pago.
Estética y Diseño Visual: El diseño debe ser agresivo pero premium (sugiero fondos oscuros con un color neón de acento, tipografías gruesas y modernas tipo San Francisco o Montserrat). La página debe ser 100% responsiva (adaptable a celulares) y cargar rápido.
Estructura de la Web:
Hero Section: Título de alto impacto, video o imagen de fondo (de las mías) y un botón de llamada a la acción (CTA) para unirse.
Equipamiento: La sección interactiva mencionada en el punto 2.
Planes y Precios: Tablas comparativas llamativas.
Portal de Miembros: Zona de autenticación conectada a la base de datos.
Genera el código utilizando tecnologías modernas (por ejemplo, React, Next.js, y Tailwind CSS para el diseño, además de Framer Motion para las animaciones interactivas). Explica paso a paso cómo conectar la base de datos para asegurar el soporte de los 10,000 usuarios.
